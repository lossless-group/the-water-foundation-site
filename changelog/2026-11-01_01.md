# Changelog — 2026-11-01_01

## Summary

`context-v/` is now an Open Knowledge Format (OKF) v0.2 bundle. Any OKF reader can
list what's here and what each doc is for without opening a file.

## context-v

### Added
- **`type:` on all three docs in a folder:** `Issues` on the two issues, `Specs` on
  the theme-system spec. It is the Train-Case name of the folder each doc lives in.
- **`context-v/index.md`**, declaring `okf_version: "0.2"` and listing the two folders.
- **`issues/index.md` and `specs/index.md`**, one line per doc with its lede.

### Notes
- Part of the tree-wide OKF sweep; see the Context Vigilance Kit's plan,
  [[Retrofit-Every-Repo-to-OKF-Then-the-Kit-Frontmatter]].
- Every edit was made by hand. The doc diff is three added `type:` lines and nothing
  removed. No dates moved: this is a compliance change, not a content change.
- `Updates-for-April-2026.md` sits at the bundle root, not in a folder, so it carries
  no `type`. It is logged for filing.
- The site doesn't load `context-v/` into pages, so no code changed.
